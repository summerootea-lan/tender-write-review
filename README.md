# 技术标编写与评审

面向中文技术标工作的可复用 AI Skill，覆盖从要求拆解到终稿核验的八个模块。

## 功能
1. 招标要求拆解：形成事实表、要求清单与待补事项。
2. 目录规划：独立规划章节并映射评分点。
3. 正文编写：按章编写具体措施、责任、进度、成果和验收。
4. 单文档审核：核查响应、技术逻辑、文字、数字及结构。
5. 多文档查重：排除可追溯的招标原文，分别进行文字与方案相似分析。
6. 评标视角评审：依据实际评分标准分析支撑与失分风险。
7. 修改与版本复核：最小修改、重读新版、逐项闭环。
8. 终稿交付检查：核查关键承诺、目录引用、占位符及可访问的文件状态。

## 使用示例
- 使用本技能，根据招标文件先拆解要求，再规划技术标目录。
- 按已确定目录编写第三章；缺失企业材料标待补，不编造。
- 审核附件，只指出必须修改的问题并给出最小替换文字。
- 排除指定招标原文，对三份文档进行两两比对，说明计算口径。
- 核对修改版是否解决上一轮问题，并检查修改影响。

## 文件
- SKILL.md：主指令、模块路由、证据要求和输出规则。
- agents/openai.yaml：技能展示名称和默认调用提示。
- references/writing.md：目录与正文编写规则。
- references/review.md：单文档审核清单。
- references/similarity.md：多文档查重及量化口径。
- references/evaluation.md：评标视角分析规则。
- references/revision.md：最小修改、版本闭环和终稿核验。
- assets/icon.svg：展示图标（如当前导出版本包含）。

## 使用与安装

### 1. 安装技能

1. 点击仓库首页的 Code → Download ZIP，下载并解压。
2. 保留 SKILL.md、agents、assets 和 references 的目录结构。
3. 在支持 SKILL.md 的 AI 工具中，按照该工具的技能安装说明添加完整文件夹。

如果工具不支持安装技能，也可以让助手读取 SKILL.md 及其引用的参考文件，按其中规则执行任务。

### 2. 使用技能

提供本项目的招标文件、评分标准及需要处理的文档，再说明任务。

**编写技术标：**
> 使用本技能，根据招标文件拆解要求、规划目录，再按确定的目录逐章编写正文。缺失资料标记待补，不要编造。

**审核技术标：**
> 使用本技能审核附件，只指出必须修改的问题，给出原文位置、判断依据和最小替换文字。

**多文档查重：**
> 使用本技能，排除指定招标原文，对附件进行两两比对，分别分析文字、结构和方案相似性，并说明计算口径。

**复核修改版：**
> 使用本技能，核对上一轮问题是否解决，并检查修改是否引入新的矛盾。

在支持相应调用语法且已安装本技能的环境中，可使用 `$tender-write-review` 调用。

### 3. 运行条件

文档解析、图片识别、版式检查、文件生成和量化查重，需要所用 AI 工具提供对应能力。

本技能提供工作流程与判断规则，不包含独立运行的软件或专用查重引擎。量化结果须实际计算；无法完成的检查应明确说明。


## 边界
默认技术标；商务与报价按明确要求处理。不包含具体客户标书、报价、企业资质、个人信息或账户凭据。不承诺中标、无任何错误或特定评审结果；不以相似性直接认定违规，不协助掩盖关联或规避检测。
