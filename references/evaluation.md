# 评标视角

读取原始评分项、分值、档位、证明材料要求及实质性条款。建立“评分要求→对应位置→实际支撑→缺口→补强”矩阵。
分别评价符合性、覆盖程度、项目针对性、可执行性、证据充分性、评审定位便利性和可验证的优势。不要把章节篇幅、词语华丽或无据创新直接视为高分。
无完整标准时只评估内容，不编分值；档位与证据足够时才能给模拟区间，展示依据与不确定性。缺少材料不能直接认定不存在，也不能默认具备。
区分明确不符合、可能失分、一般优化；对否决风险必须关联具体要求，未见否决条款时不要宣称必然废标。不得以评委偏好替代公开标准，不承诺实际评审结果。
优先补具体方法、项目数据适配、成果样式、质量证据和验收路径；不得编造业绩、证书或承诺以制造优势。
